# 0.32.2

_Released 2026-09-25._

The `./madlib` metrics, corrected against the sentence selector it was
extracted from: pixels where the first cut had used ems, and no gap under the
inline select's underline. No API or token change. (0.32.1 was meant to be
this release and shipped without it.)

[Compare against 0.32.1 on GitHub](https://github.com/fndvit/VizVit-UI/compare/v0.32.1...v0.32.2)

## Fixed

- **`./madlib`** — the metrics now match the sentence selector this was
  extracted from: the inline select's underline sits directly under the text
  (it had a 0.1em gap), and the menu's spacing, the toggle's underline gap and
  the bar between toggle options are pixels rather than ems, so a 24px
  sentence gets the same 6px rows and 16px gutters as a 14px one instead of a
  roomier control.
